# RimKit docs site

Custom static docs themed like [team.stratware.win](https://team.stratware.win/). Markdown lives in `../docs`. Nav lives in `nav.json`.

```powershell
npm install
npm run serve
```

| Script | Role |
|--------|------|
| `npm run build` | Write HTML into `../site` |
| `npm run serve` | Build once, serve on :8000 |
| `npm run dev` | Serve and rebuild on change |
