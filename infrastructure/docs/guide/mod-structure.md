# Mod structure

```
MyMod/
  meta.lua             name, author, package id, dependencies. You edit this.
  About/About.xml      generated by rimkit mod sync. Do not edit.
  Lua/                 your scripts (main.lua runs first, the rest in name order)
  Defs/                RimWorld XML content, if you need it
  Patches/             XML patches
  Languages/English/Keyed/*.xml   strings for game.ui.translate
  Textures/ Sounds/    assets
```

Only `meta.lua` and `Lua/` are required.

## Load order

Harmony, then RimKit, then your mod. List both in `meta.lua` (`depends` and `load_after`) so the game orders them for you.

## What goes where

| Need | Put it in |
|------|-----------|
| Behavior, events, hooks, UI | `Lua/` |
| New items, recipes, research, hediffs, key bindings | `Defs/` XML ([Defs](defs-xml.md)) |
| Text players see | `Languages/<language>/Keyed/*.xml`, read with `game.ui.translate` |
| Tunable numbers | `game.config.register` in Lua, shown in the mod options |
| Data that must survive a save | `game.data.set` (or a Def, if the save refers to it) |

## Lua files

All `.lua` files under `Lua/` are loaded, `main.lua` first. They share one Lua state, so a global in one file is visible in the others. Use `local` unless you mean to share. `require("name")` loads `Lua/name.lua` from your own mod only.

## What ships

`rimkit mod ship` copies these folders: `About`, `Assemblies`, `Native`, `Lua`, `Defs`, `Patches`, `Textures`, `Sounds`, `Languages`, `News`, `Auth`, `LoadFolders.xml` and `meta.lua`. Everything else stays in your source folder.

## The kit repository

```
mod/                 RimWorld ship package (About, Assemblies, Auth, Defs, …)
src/api/             aliases.json, the naming table
src/host/            C# host (Harmony, ops, events)
src/native/          C++ core (Lua, sandbox, bindings, CLI)
src/editor/          VS Code / Cursor extension and Lua stubs
src/templates/       the mod template
infrastructure/      docs-site/, docs/, tools/
tests/               native tests and the in-game smoke mod
```
