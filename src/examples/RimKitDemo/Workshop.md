[h1]RimKit Demo[/h1]

A small tour of what mods written with RimKit can do, in one readable Lua file. It is meant to be copied from.

[h2]What it does[/h2]
[list]
[*] F9 opens a window with every colonist's best skills and a slider for how fast colonists get hungry.
[*] A message tells you when a colonist dies.
[*] The hunger speed is also a mod setting.
[*] Developers: an action in the F11 dev tools window, and a function other mods can call through game.interop.
[/list]

[h2]Requirements[/h2]
[list]
[*] Harmony
[*] RimKit
[/list]

[h2]Compatibility[/h2]
Safe to add to a running save. Removing it later leaves no errors. It stores nothing in your save.
