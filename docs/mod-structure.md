# Mod structure

```
MyMod/
  meta.lua           # name, author, package_id, depends (edit this)
  About/About.xml    # generated by rimkit mod sync (do not edit)
  Lua/**/*.lua       # runtime scripts
  Defs/ ...          # normal RimWorld XML content if needed
```

Kit repo:

```
meta.lua
src/host/
src/native/
src/examples/
src/templates/
```

Load order: Harmony, RimLuaKit, your mod.
