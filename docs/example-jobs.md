# Jobs Test

Folder: `src/examples/jobs/`

Phase 1-3 smoke mod: Lua jobs, debug window, float menu, config, defs codegen, F8 key.

```text
bin\rimkit.exe mod sync src\examples\jobs
bin\rimkit.exe mod ship src\examples\jobs
bin\rimkit.exe mod ship .
```

Enable order: Harmony → RimKit → Jobs Test.

In colony: auto window ~2s, or **F8**. Select pawn then click buttons. Check Player.log for `[JobsTest]`.

Mod settings: Options → RimLuaKit (`verbose`, `auto_window`).
